# データソース

「衆議院選挙で、どれだけの人が投票したか」のデータソース調査と、データ層の設計方針。
調査日: 2026-09-26。URL と表の中身は取得して確認済み。

## 1. 結論

一次情報源は総務省の次の3つ。

| 用途 | 資料 | 範囲 |
| --- | --- | --- |
| 全国（時代） | [第49回確定結果調](https://www.soumu.go.jp/main_content/000930924.pdf) PDF の24ページ「男女別投票者数投票率」 | 第22〜49回。比例代表は第41回から |
| 全国（第50・51回）・都道府県 | 各回の結果ページの「都道府県別有権者数、投票者数（小選挙区）」「同（比例代表）」 | 第44〜51回 |
| 年代 | 「[国政選挙の年代別投票率の推移について](https://www.soumu.go.jp/senkyo/senkyo_s/news/sonota/nendaibetu/index.html)」の「[衆議院議員総選挙における年代別投票率（抽出）の推移](https://www.soumu.go.jp/main_content/000255967.pdf)」 | 第31〜51回 |

- 全国は第22回（1946年、男女普通選挙の最初の総選挙）から。確定結果調の同じ冊子には第1回（1890年）からの「投票状況」もあるが、第21回までは納税額や性別で選挙権が限られ、有権者の意味が今と違うので載せない。
- 都道府県別は第44回から。第41〜43回は、兄弟サイト election-shugiin-timeseries の調査のとおり、総務省サイトに回ごとの結果ページがなく、第43回の e-Stat の PDF は文字が取り出せない。
- 年代別は抽出調査（§4）。都道府県別の年代別投票率は総務省にはない。都道府県が独自に出しているものは、方法も対象の回もそろわないので載せない。

出典表記: 総務省「衆議院議員総選挙・最高裁判所裁判官国民審査結果調」、総務省「国政選挙の年代別投票率の推移について」。

## 3. 読み方の決まり

- 投票率 = 投票者数 ÷ 選挙当日の有権者数。小数第2位で四捨五入すると、確定結果調に印字された男・女・計の投票率と第22〜49回のすべての行で一致する（読むたびに確かめる）。
- 「選挙区」は第22回が大選挙区（制限連記制）、第23〜40回が中選挙区、第41回からが小選挙区。確定結果調の表は第40回までは1行、第41回からは小選挙区（小）と比例代表（比）の2行。
- 都道府県別の表の行は、都道府県 + 9つの数（有権者・投票者・棄権者 × 男・女・計）。比例代表の表は都道府県の前にブロック名がつくので、行の名前の末尾で都道府県を決める。
  全国の行は、小選挙区の表は「計」、比例代表の表は「合計」（比例代表の「計」はブロックの小計）。
- Excel は先頭のシートだけを読む。2枚目のシートは「うち在外」（在外選挙人の内数）で、先頭のシートの数に含まれている。
- 表の中の「計」（男 + 女）と「棄権者」（有権者 − 投票者）は読むたびに突き合わせ、合わなければ止める。
- 第44回の PDF は `pdftotext -layout`（poppler）で読む。この表には空欄がないので、行の数値を左から順に取る。

## 4. 年代別投票率（抽出調査）

「衆議院議員総選挙における年代別投票率（抽出）の推移」の下の表（10歳代〜70歳代以上・全体 × 第31〜51回）を読む。総務省は総選挙のたびに同じ URL の PDF を差し替える。

- 全数の集計ではない。表の注記「この表のうち、年代別の投票率は、全国の投票区から、回ごとに144～188投票区を抽出し調査したもの」。
- 第46〜50回の「年齢別投票状況」（[000255968.pdf](https://www.soumu.go.jp/main_content/000255968.pdf)）の調査方法: 各都道府県から標準的な投票率を示している1市1区1町1村を抽出し（区がない県は市を2か所、村がない県は町を2か所）、そのなかで標準的な投票率を示している投票区を1か所ずつ、計188投票区（47都道府県 × 4）を抽出。
- 表の注記: 第31回の60歳代は60〜70歳、70歳代以上は71歳以上の値。第48回の10歳代は全数調査の値。
- 10歳代は第48回（選挙権年齢が18歳以上になった回）から。値は右詰めで、欠けているのは古い回。
- 上のグラフにも同じ数字と年代の名前が散らばっているので、表の見出し（最後の「回」の行）より下だけを読む。
- 「全体」の行は抽出でなく全国の投票率。第31〜51回のどの回も、確定結果調・結果ページの表から計算した全国の小選挙区（中選挙区）の投票率と一致する（`npm run verify`）。

## 5. 突き合わせ（`npm run verify`）

- 確定結果調: 目録の第22〜49回がそろう。比例代表は第41回から。
- 都道府県別: 都道府県の和 = 全国の行（小選挙区・比例代表、第44〜51回）。
- 確定結果調との照合: 第44〜49回の結果ページの全国の行 = 確定結果調（§2 の既知の差を除く）。投票率は一致。
- 年代別: 第31〜51回がそろう。10歳代は第48回から。「全体」= 全国の小選挙区（中選挙区）の投票率。

## 6. 配信データ

`npm run data` が `data/normalized/*.json` だけを入力に、`public/data/` に書き出す。

| ファイル | 次元 | 値 |
| --- | --- | --- |
| `era.json` | 制度（選挙区・比例代表）× 回（第22〜51回） | 男女別の有権者数・投票者数（全国） |
| `pref.json` | 制度 × 回（第44〜51回）× 都道府県 | 男女別の有権者数・投票者数 |
| `age.json` | 年代 × 回（第31〜51回） | 投票率（百分率、表のまま）と全体 |

## 7. 配色

`src/lib/data/palette.ts`。兄弟サイトでは色相を党に使う。このサイトに党は出ないので、男女計は無彩色（墨）、男女は兄弟サイトの性別の内訳と同じ Okabe–Ito の2色（男性 空色・女性 朱色）。
地図の明度は投票率の関数。目盛りは2つから選ぶ。

- この回の範囲（既定）: 選んだ回・制度・男女の都道府県の最低〜最高を、外側の整数の%に丸めたもの。1回の中の県の差は15ポイントほどなので、共通の目盛りでは濃淡の差が見えにくい。
- 全回共通: 全回・全都道府県・男女の投票率（45.1〜79.1%）が収まる 40〜80%。どの回でも同じ明るさが同じ投票率になる。

都道府県の一覧（投票率の順位）の棒の尺度は地図と同じ目盛りで、全国の投票率を基準線で重ねる。尺度は一覧の見出しに書く。
時代・年齢のビューには一覧を置かない。グラフと同じ値を並べ直すだけになるため（japan-data の通勤「利用交通手段」と同じく、1240px の枠いっぱいにグラフを置く）。
